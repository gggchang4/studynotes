## 1. 一张数据表怎样成为模型输入

仍使用运输时长的原创教学数据：

| parcel_id | distance | weight | hours |
| --- | --- | --- | --- |
| A | 1 | 1 | 3 |
| B | 2 | 1 | 5 |
| C | 1 | 3 | 4 |

`parcel_id` 用于辨认样本，不自动是合适的预测特征；`hours` 是目标，不能同时放入输入。pandas 的 `DataFrame` 按列保存表格；一列通常是 `Series`。转为数值数组前，先明确特征名单和顺序。

```python
# Python 3.12.14，NumPy 2.3.5，pandas 3.0.1；CPU
import numpy as np
import pandas as pd

df = pd.DataFrame({
    "parcel_id": ["A", "B", "C"],
    "distance": [1.0, 2.0, 1.0],
    "weight": [1.0, 1.0, 3.0],
    "hours": [3.0, 5.0, 4.0],
})
features = ["distance", "weight"]
X = df[features].to_numpy(dtype=np.float64, copy=True)
y = df["hours"].to_numpy(dtype=np.float64, copy=True)
w = np.array([2.0, 0.5], dtype=np.float64)
y_hat = X @ w + 0.5
print(X.shape, y.shape)       # (3, 2) (3,)
print(y_hat.tolist())         # [3.0, 5.0, 4.0]
print(np.mean((y_hat-y)**2))  # 0.0
```

零误差只因为数据是为讲解构造的，不能据此评价模型泛化。这里保留 double 精度便于核查；大规模训练常使用其他精度，需按任务与硬件选择。

DataFrame 与 ndarray 的职责可对照 [pandas 的表格教程](https://pandas.pydata.org/docs/getting_started/intro_tutorials/01_table_oriented.html) 和 [NumPy 2.3 Quickstart](https://numpy.org/doc/2.3/user/quickstart.html)。如果对含字符串的全部表格直接调用 `to_numpy()`，可能得到 `object` 数组，不再是预期的高效数值矩阵。

表格读写也应保留列类型与样本标识：`read_csv` 会解析文本字段，不能仅凭文件后缀推断每列语义；标识符中的前导零、日期时区与缺失值约定都可能影响数据含义。分组聚合先确定分组键，再确定统计量。上表按 `distance` 分组，距离 1 的时长均值为 3.5、样本数为 2，距离 2 的均值为 5、样本数为 1；只比较均值而不看样本数，会掩盖估计可靠性差异。合并与聚合后还要保留标签对齐。

## 2. shape、axis 与降维

对 $X\in\mathbb R^{n\times d}$，`shape == (n, d)`，第 0 轴是样本，第 1 轴是特征。`sum(axis=0)` 沿样本方向归约，留下每个特征的和；`sum(axis=1)` 沿特征方向归约，留下每个样本的和。

以上例为准：

| 表达式 | 结果形状 | 数值或解释 |
| --- | --- | --- |
| `X.sum(axis=0)` | `(2,)` | `[4, 5]`，每列求和 |
| `X.sum(axis=1)` | `(3,)` | `[2, 3, 4]`，每行求和 |
| `X.mean(axis=0, keepdims=True)` | `(1, 2)` | 每个特征的样本均值 |
| `X[:, 0]` | `(3,)` | 第一列，样本轴保留但特征轴消失 |
| `X[:, [0]]` | `(3, 1)` | 第一列，保留二维结构 |

`axis` 指定被计算/归约的轴，不是“输出是行还是列”的通用同义词。`keepdims=True` 把被归约的轴保留为长度 1，常用于后续广播。

一维数组 `(d,)` 没有显式的行/列向量方向，`.T` 不会把它变成 `(d,1)`；需要 `x[:, None]` 或 `reshape(d,1)`。`reshape` 改变形状但不等于转置；`transpose` 置换轴，也不保证内存连续。

## 3. 广播：从最右端对齐形状

NumPy 广播（broadcasting）从形状最右端向左比较，每一维必须相等或其中一个为 1；缺失的前导维按 1 处理。例如 `(3,2)` 与 `(2,)` 可运算，等价于给每一行使用同一组两个数。

训练均值为 $\mu=(4/3,5/3)$，因此 `X - X.mean(axis=0, keepdims=True)` 按列中心化，结果为

$$
\begin{bmatrix}-1/3&-2/3\\2/3&-2/3\\-1/3&4/3\end{bmatrix}.
$$

这是把训练数据放进新的坐标原点。应用到验证、测试或新数据时，要复用训练均值；如果重新计算均值，就改变了输入含义。

> [!warning] 最容易静默发生的形状错误
> `(3,1) - (3,)` 会广播为 `(3,3)`，算出所有预测与所有标签的两两差值，而不是三个一一对应的误差。`(3,2) - (3,)` 则不兼容。广播规则只负责形状，不能判断哪个轴代表样本。

广播本身常避免显式复制较小输入，但运算结果仍可能很大。例如构造 $n\times n$ 的两两距离矩阵需要二次存储。规则与内存边界见 [NumPy 2.3 Broadcasting](https://numpy.org/doc/2.3/user/basics.broadcasting.html)。

## 4. 索引、拷贝与标签对齐

NumPy 基本切片通常返回视图（view），与原数组共享存储；高级索引（整数数组、布尔筛选）通常返回拷贝。修改视图可能改变原数组，必要时显式 `.copy()`。一维和多维索引的规则详见 [NumPy 索引文档](https://numpy.org/doc/2.3/user/basics.indexing.html)。

pandas 的 `.loc` 按标签选择，`.iloc` 按位置选择；Series 参与运算时通常按索引标签对齐。这与 ndarray 的位置运算不同。若特征与标签分别打乱后再转为数组，列数和行数都可能正确，样本对应关系却已经错误。

合并表格还要注意键的基数。如果左右两表同一个键各有两行，连接可能产生四行；这会改变样本权重和重复情况。`merge(..., validate='many_to_one')` 等参数可表达预期关系。按 ID 对齐、检查重复和时间可用性，属于学习问题本身的一部分，不只是“清洗格式”。

## 5. 缺失值与数值类型

缺失值不是 0，也不是“没有影响”。浮点数组中的 NaN 会传播到很多运算；`nanmean` 忽略缺失项，是一个明确的统计选择，而非万能修复。用均值填补、加缺失指示列、建模缺失机制，是不同策略，详见 [[AI/02-数据与机器学习基础/01-数据理解与特征工程|数据理解与特征工程]]。

整数数组不能自然存储 NaN，某些定长整数运算还可能溢出。浮点计算检查 `isfinite` 可以识别 NaN 与无穷，但发现异常后仍需定位其来源。数组所占字节数近似为 `元素数量 × dtype.itemsize`；额外副本与中间结果会增加峰值内存。

随机样本宜使用显式生成器，如 `rng = np.random.default_rng(42)`；它把随机状态作为可传递对象。种子和 NumPy 版本都应在需要复现时记录，不能仅凭种子假设所有未来版本和并行环境逐位一致。

## 6. SciPy 与 Matplotlib 各补什么能力

SciPy 建立在 NumPy 数组上，为线性代数、优化、统计分布、稀疏矩阵和信号处理提供算法。典型映射是：线性方程用 `linalg.solve`，最小二乘用 `linalg.lstsq`，数值优化用 `optimize`，分布函数用 `stats`。这些接口的前提和返回值需要分别阅读，例如优化器的终止状态不能直接当作“已找到全局最优”。本轮只核对 [SciPy 线性代数说明](https://docs.scipy.org/doc/scipy/tutorial/linalg.html)，未在当前环境运行 SciPy。

Matplotlib 中 `Figure` 是整体画布，`Axes` 是一个绘图区，`Axis` 表示坐标轴；通常用 `fig, ax = plt.subplots()`，再由 `ax.plot`、`ax.scatter` 等表达关系。与只记 `plt.plot` 相比，理解对象分工更容易组织多个图。见 [Matplotlib Quick start guide](https://matplotlib.org/stable/users/explain/quick_start.html)。本篇没有未运行的绘图代码块。

可视化首先要回答一个统计问题：

| 问题 | 图形 | 需要标清的条件 |
| --- | --- | --- |
| 某个特征怎样分布？ | 直方图、箱线图、ECDF | 单位、分箱或样本量 |
| 两变量怎样相关？ | 散点图 | 是否对数轴、分组、重叠点 |
| 训练是否稳定？ | 随 step/epoch 变化的曲线 | 指标定义、训练或验证、平滑方式 |
| 模型如何出错？ | 混淆矩阵、残差图 | 类别顺序、归一化口径、数据集 |
| 多次比较是否稳定？ | 带区间的点图 | 区间含义、重复次数、独立单元 |

> [!note] 图是论证的一部分
> 截断纵轴、按各自不同的最大值归一化、只画最好的随机种子、把模拟曲线当实测，都会改变读者理解。图题应让人知道数据来自哪里、点和误差条代表什么。能够生成图片不等于结论已得到证明。
