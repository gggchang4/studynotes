## ai-knowledge-map.svg

- 类型：本知识库自制 SVG 教学示意；源文件即 SVG，不含外部图片素材。
- 内容来源：学习路线与章节映射；用于区分共享主干、并列方向和各方向的前置。
- 图中文字与公式：本图不含实验数据或公式；箭头只表示本库讲解顺序，不代表所有分支的严格先修链。
